# Image Prompt Library v0.11.4

`v0.11.4` is being prepared as a maintenance release. The current stable release remains [v0.11.3](v0.11.3.md). Do not treat a published prerelease as the default update until package and cross-platform checks have passed.

## Clearer browsing and image review

- Image details use a compact prompt toolbar and distinct actions for generating from text or using an image as a reference. Icon actions retain accessible labels.
- Generation review separates the saved result from the editable draft. Optional metadata and generation details stay out of the main reading path.
- Shorter labels, grouped settings, and mobile spacing reduce clutter. Image actions no longer overlap the result frame, and batch navigation arrows remain visible over light images.
- Library can load further pages instead of stopping at the initial result limit. Failed page requests retain existing cards and can be retried; outdated responses cannot append to a different search.

## Safer everyday actions

- Saving a generated image blocks rapid duplicate activation. If a save committed but its response was lost, retrying returns the same saved reference instead of creating another one or getting stuck on a conflict.
- This retry recovery applies to saves recorded by this version. Older completed saves without the durable acceptance marker are not reinterpreted, and a deleted target is not recreated.
- Loading provider status no longer briefly reports that generation is unavailable. Completed generation results do not retain the submission's queued message.
- Keyboard focus and cancellation handling preserve unsaved edits, respect disabled controls while saving, and return to the relevant action after dialogs close.
- Prompt copying reports the language actually used when the preferred translation is missing. Returning from editing retains the selected prompt language.

## Upgrade and verification boundaries

This release adds no database migration. The [migration 012 backup and rollback boundary introduced in v0.11.3](v0.11.3.md#database-upgrade-and-backup-compatibility) still applies when upgrading from older releases.

Local verification includes frontend regression tests, production and read-only demo builds, and a real three-image ChatGPT generation batch saved and reopened individually on desktop and a 390px browser viewport. Failure recovery uses controlled automated tests; this is not certification of every provider failure or physical phone device.

Before stable promotion, the exact candidate must pass full CI, archive/manifest/checksum verification, and public-package install, update, rollback, backup and restore checks on Windows, macOS and Linux using v0.11.3 as the baseline. The published candidate assets must be promoted unchanged.

On mobile, result review still places the prompt before the image. This is a known layout tradeoff, not a new feature or a claim of complete mobile-device coverage.
