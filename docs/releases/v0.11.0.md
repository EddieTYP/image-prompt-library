# Image Prompt Library v0.11.0

`v0.11.0` is the current stable release, available from [GitHub Latest](https://github.com/EddieTYP/image-prompt-library/releases/latest). Normal install and update commands select it by default.

This release adds **Grok image generation and title suggestions**, alongside multi-image cards and easier batch organization.

## Generate with Grok

You can now connect a Grok account alongside ChatGPT. In **Config → Providers**, choose **Grok OAuth**, complete the browser authorization, then select **Grok** in the generation window. You do not need to enter an API key.

Grok supports text-to-image generation and editing with up to three reference images. Available controls include Auto, 1:1, 3:4, 9:16, 4:3, and 16:9 aspect ratios; Low or Medium quality; and 1K or 2K resolution. The image model is `grok-imagine-image-2.0`.

Generate one image or a set of 3, 5, or 10, review the results, and save the ones you want. ChatGPT remains available; switching provider shows the controls supported by that provider.

**Grok OAuth is experimental.** Availability, quotas, and charges depend on the connected xAI account. A successful connection does not guarantee generation access or unlimited use. Prompts and selected reference images are sent to xAI when you generate.

## Choose a default provider and suggest titles

**Default AI provider** in Config sets the starting provider for new generation sessions and ordinary Add/Edit title suggestions. The preference stays in the current browser; you can still choose another provider for an individual generation session.

Use **Suggest title** in Add, Edit, or a generated-result save form to create a short title from the prompt text. The suggestion is a preview: choose **Use title** before it replaces the title field.

- Both ChatGPT and Grok can suggest titles.
- Generated results use the provider that created them, with a **via ChatGPT** or **via Grok** label.
- Only prompt text is sent for title suggestions—not images, the existing title, tags, collections, or notes.
- A disconnected provider prompts you to reconnect. The app does not silently switch to another provider.

## Keep an image set in one card

One Library card can hold several images. In **Edit**, reorder them, choose the primary image shown on the card, change result/reference roles, or remove an individual image.

When reviewing a generation set, save the first result as a new card, then add later results to that same card. You can browse the images together in one detail window instead of creating a separate card for every result.

New generated images retain their provider and model details, visible in the item detail view. Each image keeps its own information when images from different generation sessions share a card. Older images without recorded details are not assigned a guessed provider or model.

## Organize several cards at once

Batch **Tag** now provides a searchable picker with existing-tag suggestions and multiple selection. Batch **Move** provides a collection picker, so you no longer need to type an exact collection name.

The selection toolbar is more compact on mobile, with Tag and Move directly accessible and other actions under **More**. Generation menus use consistent option spacing, and cancellation controls are easier to read.

## Updating and getting started

Back up your library before updating. Your existing cards do not require a provider connection; browsing, editing, and organization remain local. Connecting Grok is optional and separate from your ChatGPT connection.

Existing installations can update with:

```text
image-prompt-library update
```

See [installation and updates](https://github.com/EddieTYP/image-prompt-library/blob/main/docs/INSTALLATION.md), [backup and restore](https://github.com/EddieTYP/image-prompt-library/blob/main/docs/BACKUP_AND_RESTORE.md), and the [generation guide](https://github.com/EddieTYP/image-prompt-library/blob/main/docs/GENERATION.md). The online demo remains read-only and does not connect to providers or generate images.
