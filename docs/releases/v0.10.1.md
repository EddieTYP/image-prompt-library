# Image Prompt Library v0.10.1

v0.10.1 fixes update checks that could fail after GitHub's shared anonymous request limit was reached.

- Update checks now use the stable release link first. Opening Settings reuses the recent result; choose **Check for updates** when you want to refresh it.
- Windows, macOS, and Linux can install a selected version without first querying GitHub's release API.
- If the latest release does not support the current platform, the installer can still find an older compatible stable release.

Your library, provider connection, and generation data are unchanged.
