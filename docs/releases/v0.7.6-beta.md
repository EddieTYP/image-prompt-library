# Image Prompt Library v0.7.6-beta - Library Power-User Polish

Patch beta release focused on making larger local prompt libraries easier to search, sort, clean up, and manage in batches.

## Added

- Structured search filters for day-to-day library triage:
  - `tag:<name>`
  - `collection:<name>`
  - `source:<text>`
  - `model:<text>`
  - `favorite:true`
  - `archived:true`
  - `has:image`
  - `has:prompt`
  - `created:30d`
  - `updated:7d`
- Visible sort controls for updated date, created date, title, source, and model.
- `sort:` query support so saved/searchable queries can carry their own ordering.
- Batch reference actions from card selection mode:
  - archive and restore
  - favorite
  - add tags
  - move to collection
  - delete
- Local library cleanup tools in Config:
  - preview broken image records
  - preview unreferenced media files
  - apply cleanup only after preview

## Improved

- Active search/filter/sort chips are visible on desktop and mobile.
- Archived references can be reviewed with `archived:true` before restore or delete actions.
- Cleanup protects against symlink traversal and rejects unsafe cleanup paths.
- Config/Cleanup panels no longer sit under floating action controls.
- Mobile selection and search layouts were checked against a real 390px-wide browser viewport.
