# Image Prompt Library v0.8.0 - Native Windows Quick Start

## Native Windows PowerShell

v0.8.0 is the first release planned to support the native Windows PowerShell quick start. It requires Windows 10/11, PowerShell 5.1+, and Python 3.10+; Python is never installed automatically.

```powershell
irm https://raw.githubusercontent.com/EddieTYP/image-prompt-library/main/scripts/install.ps1 | iex
```

The installer starts the app in the background and opens the local browser view. Manage it with:

```powershell
image-prompt-library status
image-prompt-library doctor
image-prompt-library stop
image-prompt-library start
```

The public bare command resolves to a `.cmd` shim, which launches a differently named internal PowerShell delegate with an explicit `-NoProfile -ExecutionPolicy Bypass -File` child command. This preserves normal command use under a `Restricted` caller policy without changing the user's policy.

## Release Integrity and Recovery

The installer accepts only release manifests that advertise the Windows PowerShell capability, and verifies the manifest, checksum file, and calculated SHA256 before extraction. Non-loopback remote release sources require HTTPS. Version changes are serialized per prefix and transactional for handled failures: an update that cannot switch or start restores the previous selection and managed runtime where possible. This is not durable recovery from an OS or power crash. Use `image-prompt-library rollback` to select a validated previous installed version explicitly.

Private library data stays outside versioned app code. Optional sample data remains available through `image-prompt-library sample-data <en|zh_hans|zh_hant>`. Default uninstall preserves the private library; `image-prompt-library uninstall --delete-library` requires an explicit destructive choice.

## Platform and Privacy

macOS, Linux, and WSL remain supported through the existing Bash installer. The application remains local-first: prompt data, SQLite storage, and images stay on the user's machine unless the user chooses an external service.

## Release Gates

v0.8.0 release gates include the full Ubuntu CI suite, the Windows native installer smoke test, and post-release asset QA. Post-release asset QA is a release gate and is not represented here as completed.
