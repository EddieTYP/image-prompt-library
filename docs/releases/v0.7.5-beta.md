# Image Prompt Library v0.7.5-beta — API Safety and Focus Reliability

Patch beta release focused on making generation history safer to inspect and improving keyboard/focus behavior in core panels.

## Fixed

- Generation job API responses no longer include raw base64 `data_url` payloads for input images.
- Public generation job responses now return safe metadata flags (`has_data_url`, `data_url_redacted`) instead of embedding original image data.
- Filters and Config drawers are inert while closed, so keyboard focus and assistive technology no longer enter hidden offscreen panels.
- Detail modals now declare dialog semantics, keep Tab navigation inside the modal, close with Escape, and restore focus to the opener.
- Gallery cards are keyboard-activatable, allowing detail modals to return focus reliably after close.

## Improved

- Added regression coverage for redacted generation job responses across list/detail/action endpoints.
- Added frontend static coverage for drawer inertness, Escape handling, modal focus trapping, and keyboard card activation.
- Added a persisted Codebase Memory graph artifact for maintainability and future impact analysis.

## Notes

- Live generation remains local-install only; the GitHub Pages demo stays read-only.
- No database schema change.
- Update an installed app with:

```bash
image-prompt-library update --version v0.7.5-beta
```

- Roll back if needed with:

```bash
image-prompt-library rollback
```
