# Image Prompt Library v0.10.2

`v0.10.2` is the current stable release. Normal install and update commands select it by default.

v0.10.2 refreshes the model choices used to coordinate local image generation through ChatGPT / Codex OAuth.

- `gpt-5.6-terra` is the recommended default for new generation requests.
- `gpt-5.6-sol` and `gpt-5.6-luna` remain available as explicit alternatives.
- Custom configured orchestrator models remain available after the built-in choices.
- `gpt-image-2` remains the image model.
- Source builds use patched `Vite 8.2.2`; installed app behavior is unchanged.

Existing Library items, provider connections, and completed generation records are unchanged.
