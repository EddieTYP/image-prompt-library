# Image Prompt Library v0.7.7-beta - Generation Hardening

Patch beta release focused on making local generation provider readiness, stalled-job recovery, and live OAuth generation review clearer and safer.

## Added

- Provider readiness fields for generation providers:
  - `status`
  - `message`
  - `can_generate`
- Generation UI gating based on provider readiness, so unavailable providers cannot submit generation jobs.
- Stale running-job recovery after the 10-minute timeout, with clearer retry/mark-failed actions.
- Live QA record for ChatGPT / Codex OAuth connection and a successful live text-to-image generation job.

## Improved

- Broken saved ChatGPT / Codex OAuth credentials are surfaced as an auth attention state instead of a generic disconnected state.
- The generation panel prefers a ready non-manual provider when one is available.
- Failed and stale generation job actions wrap more cleanly in queue/history rows.
- Compact generation controls avoid long provider text in the toolbar; ready providers now show `Ready` while keeping the full provider label in tooltip/accessibility text.
- Mobile generation controls fit a 390px-wide viewport without horizontal page overflow.
