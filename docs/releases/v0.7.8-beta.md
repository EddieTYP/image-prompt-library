# Image Prompt Library v0.7.8-beta - Install & Onboarding Polish

Patch beta release focused on making a new local install easier to understand and diagnose.

## Added

- A first-run empty-library panel with clear paths to add a prompt, open Config, install optional sample data, or connect optional generation.
- A compact Local Setup summary in Config for app, library, database, update, and generation readiness details.
- `image-prompt-library status` for a short local-install summary, plus clearer `doctor` headings and next steps.

## Improved

- Windows Git Bash release installs handle CRLF checksum output and tar extraction compatibility more reliably.
- First-run mobile views hide floating Add, Generate, and queue controls, so onboarding content remains readable and actionable.

## Verification

- GitHub PR CI passed on the merged `main` commit.
- Focused frontend/static checks and the production frontend build passed before release.
- Independent live review covered the local first-run flow on desktop and a 375px-wide mobile content viewport, including Config drawer open/close behavior and no horizontal overflow or floating-control overlap.
- Release-asset workflow completed successfully and uploaded the release archive, manifest, and checksum.

## Notes

- GitHub Pages remains a read-only public prompt catalogue. Local setup, private libraries, and generation stay local-install features.
- Private library data is not bundled in the release archive.
- Update an installed app with:

```bash
image-prompt-library update --version v0.7.8-beta
```

- Roll back if needed with:

```bash
image-prompt-library rollback
```
