# Image Prompt Library v0.11.2

`v0.11.2` is the current stable release, available from [GitHub Latest](https://github.com/EddieTYP/image-prompt-library/releases/latest). Normal install and update commands select it by default.

This maintenance release simplifies ChatGPT image generation and editing. Your Library, previous results, and existing OAuth connection remain available.

## Generate and edit without selecting a chat model

ChatGPT / Codex image generation now uses the backend's direct Images generation and editing endpoints. The **terra / sol / luna chat-model selector** has been removed from the image composer because these requests no longer need a chat model to invoke an image tool.

Enter your prompt, optionally add reference images, choose the available aspect ratio and quality settings, then generate as before. Your existing OAuth connection is still used; no API key is required for this route.

The existing workflow remains available:

- Ordered references from uploads, Library images, and previous results.
- Single-image requests and generation sets, queue progress, and result review.
- Save as a new item, attach to an existing item, and use a result as an editing input.
- Manual retry and failed-job recovery controls.

ChatGPT title suggestions still use a chat model. Grok generation and title suggestions are unchanged.

## Existing results and queued jobs

Saved Library items, previous results, and historical job settings remain available. Queued ChatGPT image jobs and manual retries use the direct Images route. An old job's chat-model choice remains part of its history but is not sent with the new image request.

`IMAGE_PROMPT_LIBRARY_CODEX_ORCHESTRATOR_MODELS` no longer controls ChatGPT image generation. There is no automatic fallback to the old Responses route or automatic second image request after a failed request.

## Quality and model labels

Quality and aspect-ratio controls express requests, not guarantees. The service may report a different quality or return different dimensions. New jobs keep the requested settings, supported server-reported fields, and decoded image dimensions separately for diagnostics. Missing information in older records is not reconstructed.

A successful request or a requested model label does not establish the identity of the model that produced the image. This change does **not** add verified GPT Image 2.5 support or guarantee that a High request produces High-quality output.

The OAuth integration follows the Codex client implementation; it is not a guaranteed public third-party API contract. Availability, account limits, and upstream connection failures still apply. Prompts and selected reference images are sent to the provider when you generate or edit.

## Updating

Back up your Library before updating. Existing installations can update with:

```text
image-prompt-library update
```

See [installation and updates](https://github.com/EddieTYP/image-prompt-library/blob/v0.11.2/docs/INSTALLATION.md), [backup and restore](https://github.com/EddieTYP/image-prompt-library/blob/v0.11.2/docs/BACKUP_AND_RESTORE.md), and the [generation guide](https://github.com/EddieTYP/image-prompt-library/blob/v0.11.2/docs/GENERATION.md).
