# Image Prompt Library v0.10.0 - Explore, appearance choices, and smoother generation review

`v0.10.0` introduced the features below. `v0.10.2` is the current stable release; it also includes the more reliable update checks from `v0.10.1` and refreshed GPT-5.6 generation model choices.

## Explore and Library

- Browse non-empty Collections in a normal scrolling directory.
- Open item detail directly from a preview image; use the Collection heading or count to enter the existing filtered Library view.
- Preserve natural image ratios in Explore, Library, item detail, and multi-image previews instead of forcing one crop.
- Keep Explore focused on browsing while selection and batch management remain in Library.
- Choose a Red, Green, or Purple appearance. The choice stays in your browser and is not added to library data, backups, samples, or demo exports.

## Generation review

- Review 1, 3, 5, or 10 generated results as one set without losing the original batch position.
- Move to the next result after Save as new, Attach, Discard, or Retry. Use as draft pauses the review until you resume it.
- Keep Retry individual and reconnect its replacement result to the same review position.
- See a short summary after the set is reviewed.
- Work Queue shows compact result previews and unfinished review work.
- Save as new uses a dedicated workspace and hides internal IDs.

Item-level multi-image delete, reorder, role, and primary-image management are not part of this release.

## Safety and privacy

- Block write requests sent from another website.
- Guard generation actions against duplicate or conflicting result changes.
- Recover interrupted result saves before discard or retry.
- Keep OAuth credentials, provider configuration, and local session data outside library backups, sample packs, and public demo exports.
- Keep GitHub Pages static, read-only, and credential-free.

## Install and update

Follow the [installation guide](../INSTALLATION.md) for a new install. Existing installations can update with:

```text
image-prompt-library update
```

## Compatibility

`v0.10.0` supports Windows, macOS, Linux, and WSL 2. `v0.9.0` remains available from [GitHub Releases](https://github.com/EddieTYP/image-prompt-library/releases) if you need the previous version.
