# Image Prompt Library v0.10.0 - Explore, Appearance, and Continuous Batch Review

v0.10.0 starts as a prerelease candidate. `v0.9.0` remains the default stable install and update target until the candidate passes the full release gate. Testers can select `v0.10.0` explicitly; stable promotion reuses the same tag and assets.

## Explore and Library

- Replace the former constellation with a normal-scroll directory of non-empty Collections.
- Open item detail directly from a preview image; use the Collection heading or count to enter the existing filtered Library view.
- Preserve natural image ratios in Explore, Library, item detail, and multi-image previews instead of forcing one crop.
- Keep Explore focused on browsing while selection and batch management remain in Library.
- Add browser-local Red, Green, and Purple Appearance presets. The selected preset is not written to library data, backups, samples, or demo exports.

## Continuous Generation-set review

- Review 1, 3, 5, or 10 generated results as one set without losing the original batch position.
- Continue automatically after Save as new, Attach, Discard, or Retry; pause with Use as draft and return with Resume review.
- Keep Retry individual and reconnect its replacement result to the same review position.
- Show a final saved, attached, discarded, retrying, failed, and cancelled summary.
- Give Work Queue sets compact result previews and access to unfinished review work.
- Use a dedicated Save as new workspace and show only understandable generation details while retaining full internal provenance.

Item-level multi-image delete, reorder, role, and primary-image management are not part of this release.

## Safety and privacy

- Reject browser API writes from a mismatched origin or an explicitly cross-site request.
- Serialize result acceptance and discard repair so concurrent actions do not duplicate or lose result references.
- Resume interrupted result saves before discard or retry, and atomically repair incomplete stored image files.
- Keep OAuth credentials, provider configuration, and local session data outside library backups, sample packs, and public demo exports.
- Keep GitHub Pages static, read-only, and credential-free.

## Install and update behavior

Normal install and update commands skip prereleases. To test this candidate, select it explicitly:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $installer -Version v0.10.0
image-prompt-library update --version v0.10.0
```

```bash
curl -fsSL https://raw.githubusercontent.com/EddieTYP/image-prompt-library/main/scripts/install.sh | bash -s -- --version v0.10.0
image-prompt-library update --version v0.10.0
```

## Release gate

Stable promotion requires frontend, backend, migration, privacy, backup/restore, static-demo, and desktop/mobile workflow checks, followed by public Windows, macOS, and Linux clean-install, update, rollback, and uninstall smoke. The prerelease check must also confirm that GitHub Latest still points to stable `v0.9.0`. No paid generation request is required for the automated gate. A final live-provider smoke remains useful as separate QA for upstream OAuth and image-generation compatibility.
